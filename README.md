# Pest CV Project

Welcome to the **Pest CV Project**! This repository contains a computer vision application for detecting and classifying pests using images. The project leverages modern machine learning techniques to assist in pest management and agricultural monitoring.

## Features

- Upload images for pest detection and classification.
- Real-time predictions using a trained deep learning model.
- User-friendly web interface powered by `app.py`.

## Getting Started

### Prerequisites

- Python 3.8+
- Required libraries (see `requirements.txt`)

### Installation

```bash
git clone https://github.com/yourusername/pest_cv_project.git
cd pest_cv_project
pip install -r requirements.txt
```

### Usage

Start the web application:

```bash
python app.py
```

Open your browser and navigate to `http://localhost:5000` to use the app.

